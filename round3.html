How This Unified Platform Works

Attendance Prediction & Real-Time 3D Space Math

1. Attendance Predictor Math

N_total = N_conducted + R_remaining
Req_75 = ceil( 0.75 × N_total )
Classes To Attend = max( 0, Req_75 - Attended )
Safe Bunks = R_remaining - Classes To Attend

If Classes To Attend > R_remaining, it triggers an Irreversible Detention Alert.

2. 3D Free Class Locator & Safe Window

Safe Window = Consecutive free periods × 50 minutes
