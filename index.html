How This Calculator Works & The Formulas

Complete logic breakdown from SRM timetable periods

Semester Bounds

Official Semester Start: 29th August 2026 | Semester End: 29th November 2026.
All calculations exclude Saturdays & Sundays and strictly aggregate period occurrences based on the official School of Electrical and Electronics Engineering slot matrix.

1. Total Classes & Classes Attended ($A$)
N_total = N_conducted (Aug 29 → Today) + R_remaining (Tomorrow → Nov 29)
Attended Classes (A) = round( (Current % / 100) × N_conducted )

If an approved On-Duty (OD) day is registered, any missed periods during that window are added to $A$ as excused presence.

2. Surviving Danger Zone (75% Cutoff)
Req_75 = ceil( 0.75 × N_total )
Classes Must Attend (X_75) = max( 0, Req_75 - A )
Safe Bunks Allowed = max( 0, R_remaining - X_75 )
3. Irreversible Detention Alert
Max Attainable % = ( (A + R_remaining) / N_total ) × 100
If (Max Attainable % < 75%) OR (X_75 > R_remaining) → IRREVERSIBLE DETENTION

When this condition triggers, even attending 100% of all future classes cannot prevent exam debarment.

4. Target 90% Distinction Zone
Req_90 = ceil( 0.90 × N_total )
Classes to 90% = max( 0, Req_90 - A ) [if ≤ R_remaining]
